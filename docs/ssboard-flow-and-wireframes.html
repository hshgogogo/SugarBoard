SSBoard 业务流程图与页面原型图

低保真视觉草案，供 PRD 评审、页面结构确认和 Canva 汇报设计参考。

业务流程图

1. 数据接入 开放 API 授权报表 手工导入
2. 清洗建模 字段标准化 实体映射 口径对齐
3. 榜单计算 指标快照 日榜周榜 涨跌分析
4. 页面展示 首页总览 排行榜 详情页
5. AI 分析 NL2SQL 自动图表 脚本沙箱
6. 结果产出 图表导出 分析摘要 汇报材料
主流程从数据接入开始，经过标准化和榜单计算后进入前台展示，再由 AI 能力完成更深的分析与产出。
