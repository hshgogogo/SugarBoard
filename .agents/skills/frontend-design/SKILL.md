# Frontend Design

- Implement UI from `spec.md` and `api-contract.yaml`.
- Keep components purposeful, state flows explicit, and API integration contract-first.
- Preserve frontend ownership boundaries and avoid backend drift.
- Favor reusable components and observable loading, error, and empty states.
- Return changed files, checks, and open UI risks clearly.
