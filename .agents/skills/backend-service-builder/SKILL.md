# Backend Service Builder

- Build services from `spec.md`, `architecture.md`, and `api-contract.yaml`.
- Keep route, service, persistence, and async job boundaries explicit.
- Model validation, errors, and retries deliberately.
- Own data models, migrations, auth, and execution reliability.
- Report API gaps or contract mismatches before coding around them.
