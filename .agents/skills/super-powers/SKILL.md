# Super Powers

- Drive work through requirement, architecture, implementation, QA, release, and human approval.
- Package requests as `Goal`, `Deliverable`, `Inputs`, `Constraints`, `Done Definition`, and `Return Format`.
- Keep implementation roles parallel and isolated once architecture is ready.
- Escalate risks, blocked dependencies, and gate failures early.
- Prefer synthesis, arbitration, and handoff quality over direct feature coding.
